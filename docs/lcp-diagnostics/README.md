## Главная и booking

SiteGuru использует Google PageSpeed Insights; документация указывает мобильный профиль по умолчанию, но подключённый отчёт не возвращает полный конфиг и трассировку: [SiteGuru](https://www.siteguru.co/seo-academy/starting-an-seo-audit). Локальные запуски использовали Lighthouse 13.6.0/Chrome 156, simulate throttling, CPU 4×, RTT 150ms, 1638,4Kbps, 412×823/DPR 1,75. Конфигурация и место выполнения замера влияют на сравнимость: [Google](https://developers.google.com/speed/docs/insights/v5/about).

Свежие public production-трассировки: главная Performance 96, LCP 2,021 с, TBT 70ms; booking Performance 80, LCP 1,355 с, TBT 674ms. SiteGuru показывает 83 и 85 соответственно. Причину всей разницы баллов установить по этим данным нельзя.

На booking подтверждён основной тяжёлый источник JavaScript: https://bookonline24.ru/widget.js. Передано 816 979 байт, размер распакованного скрипта 3 259 033 байта. Lighthouse относит к нему около 1,64 с script evaluation и длинные задачи 424, 168, 147ms и др. Ускорение собственных мелких элементов страницы не устраняет эту нагрузку поставщика. Код SDK, проверки разрешённого домена и выбор дат не изменялись.

Для обсуждения с Контур.Отель собраны конкретные вопросы: доступна ли облегчённая/модульная сборка availabilityCalendar; можно ли исключить неиспользуемые части общего widget.js; поддерживается ли разделение его длительной инициализации на короткие задачи. Обращение поставщику не отправлялось.

Попытки получить новый полный отчёт Google из этого окружения получили HTTP 429 как через API, так и через обычный интерфейс. Ошибка интерфейса «Не удалось перейти по адресу» сопровождалась HTTP 429 его RPC. Это не подтверждает недоступность сайта: public DNS двух провайдеров согласован, сайт возвращает HTTP 200. В текущем окружении холодный native fetch дал 1701ms до заголовков; повторные запросы — 164/146ms. Эти измерения включают сетевое соединение и не изолируют время вычислений сервера. Для точного сопоставления с SiteGuru остаётся получить новые полные PageSpeed-отчёты главной и booking.

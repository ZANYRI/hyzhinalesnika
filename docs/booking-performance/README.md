## Исправления

1. Названия безымянных кнопок SDK: «Подробнее о доме», «Следующий месяц», «Предыдущий месяц». Назначение подтверждено фактическим открытием описания дома и переключением месяцев.
2. Alt у изображений SDK: типы кроватей и фотографии домов. Для фото используется отображаемое название из карточки провайдера. При неизвестной структуре остаётся нейтральная подпись. Предоставленные провайдером подписи сохраняются; при повторном использовании DOM-узла наши подписи обновляются.
3. Повторная отрисовка состояния календаря больше не перезаписывает уже установленные атрибуты. Необходимые изменения выбранных дат и доступности продолжают применяться.

Правила доступности, даты, тарифы, названия домов, сведения каталога провайдера, юридические тексты и обработка согласия сохранены. Десять файлов с соответствующими данными побайтово совпадают с основой: [protected-files.json](protected-files.json).

## Производительность: подтверждённый результат и пределы

До исправления начальная загрузка календаря вызвала 120 записей `data-hl-*`, из которых 80 повторяли установленное значение. В итоговом сценарии было 40 записей, повторных записей не было. После переключения месяцев и дома число необходимых записей достигло 120, повторные записи остались на нуле. [Профиль до](sdk-profile-before-summary.json), [проверка после](interactive-qa.json).

Сам callback нашего наблюдателя до исправления занимал суммарно около 8 мс на этой машине. Он не объясняет большую часть блокировки основного потока SDK. Ускорение всей страницы или существенное снижение TBT этим пакетом не доказано.

Проверен и отменён эксперимент с тремя отдельными Suspense-границами для блоков ниже первого экрана. Три чередующиеся пары production-замеров через одинаковые HTTP/2-прокси:

- Медианный LCP до: 3604,0 мс; после: 3606,4 мс.
- Медианная оценка Performance: 90/100 в обеих версиях.
- CLS одинаковый: около 0,0011.
- Устойчивого выигрыша нет, изменения главной страницы отменены.

[hydration-experiment.json](hydration-experiment.json) описывает отменённый эксперимент. Подтверждённого нового способа уменьшить задержку отрисовки главного фото пока нет.

## Ограничения и следующие задачи

Интеграция дополняет доступность встроенного интерфейса провайдера; платёжный сценарий и содержимое его внешних страниц не изменяются. Если структура календаря SDK изменится, проверки пропустят неизвестные элементы. Поэтому после обновлений провайдера нужно повторять проверку названий кнопок и выбора периода.

Далее остаются: большой исполняемый SDK, задержка первого экрана, расхождения каталога Контур с подтверждёнными сведениями сайта и подключение Google Search Console для фактической индексации и полевых Core Web Vitals. Прежнее сообщение SiteGuru о canonical корня прямыми HTTP-проверками не подтверждено.

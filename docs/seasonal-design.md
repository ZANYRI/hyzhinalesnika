# Сезонное оформление

Из корня проекта выполните одну команду:

| Оформление | Команда |
| --- | --- |
| Зимнее | `npm run season:winter` |
| Осеннее | `npm run season:autumn` |
| Летнее | `npm run season:summer` |

Команда проверяет наличие фото, меняет `src/data/season.json`, готовит мобильный первый экран и адаптивное изображение леса, затем собирает сайт. Снег появляется только зимой. При ошибке подготовки или сборки предыдущие настройки сезона возвращаются.

После команды перезапустите локальный сервер (`npm run start`) или опубликуйте текущую ветку обычным способом. Команды сезона сами ничего не отправляют в GitHub и не запускают деплой. Для смены через чат достаточно написать «Включите летнее оформление» (или осеннее/зимнее) при доступном актуальном проекте.

Оригиналы в `public/images` сохранены. Соответствия трёх сезонов находятся в `src/data/seasonal-images.json`, новые версии — в `public/images/seasons`. Повторения одного кадра в разных галереях используют одну версию. Интерьеры, логотипы, видео и фотографии конкретных сезонных занятий сохраняются.

Для проверки: `npm run test:season`. Внутренний флаг `--no-build` готовит сезонные файлы без сборки и используется при разработке: `npm run season:summer -- --no-build`.

## Конструктор сертификата

Страница `/special-offers#gift-certificate`: номинал от 10 000 ₽, три обложки, получатель и поздравление до 600 символов, электронный или печатный формат. Предпросмотр меняется сразу. Срок действия — один год. Заявка передаёт менеджеру все выбранные параметры; оформление оплаты и получения согласуется с менеджером.

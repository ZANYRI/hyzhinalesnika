# SEO и мобильная версия: готовность к проверке

Дата: 05.11.2026. Ветка `seo/production-ready-2026-11-05` основана на опубликованном main `5e28beb`. Production не изменён.

## Реализовано

- Metadata API: уникальные title/description, canonical и социальные метатеги; отдельная обработка 404 и поиска. Содержимое юридических документов сохранено.
- Постоянные редиректы старых URL домов и соглашения; www ведёт на основной домен с сохранением пути и query.
- Согласованные WebSite/LodgingBusiness/WebPage/Accommodation/Article/ItemList; факты берутся из существующих данных. Собственная AggregateRating удалена только из JSON-LD. Видимые оценки сохранены.
- FAQ в серверном HTML через native details, все ответы изначально закрыты, Pet friendly открывает нужный вопрос. Ссылки Header доступны обходчику.
- Sitemap содержит 17 основных страниц, включая актуальное согласие; robots позволяет увидеть noindex страницы поиска.
- Responsive images на главной, в карточках, галереях и материалах. Исходники фотографий сохранены. Для фоновых фото главной применяется quality=60; остальные изображения используют прежнее качество.
- Montserrat: подмножества 195072 байта вместо 366992, сохранены метрики, контуры, лицензия и fallback остальных символов. Имена файлов содержат хеш; immutable кеширование применяется только к этим файлам.
- SDK бронирования на главной загружается при приближении формы, каталог комнат - ближе к просмотру. В мобильном календаре исключена первоначальная инициализация desktop-варианта, зарезервировано место под календарь.
- Footer укладывается в ширины 320/390/768/1024. Улучшен контраст мелких подписей и оценки Яндекса. Поля формы звонка используют 16 px на мобильном.
- H1 страницы booking уточняет её назначение. Рядом с легендой есть пояснение о проверке ограничений тарифа; условия бронирования самостоятельно не менялись.

## Проверки

- `npm run typecheck`: успешно.
- `npm run lint`: 0 ошибок, 3 предупреждения о native img (полноразмерный lightbox и старый неиспользуемый GalleryMarquee).
- `npm run build`: успешно. Сохранились два предупреждения Turbopack о динамических файловых путях существующего журнала контактов; код журнала не менялся.
- `npm run test:booking`, `npm run test:contact`: успешно.
- `npm run test:seo`: 17 страниц, 27 внутренних целей, 6 редиректов, www, реальные 404/noindex, canonical, JSON-LD, серверный FAQ и HTTP-кеширование шрифтов.
- `scripts/subset-fonts.py --check`: успешно; сохранение контуров/метрик/полного набора символов проверено.
- Browser QA: новая сборка подставлялась в изолированном браузере по production-origin. Настоящий SDK Контур использовал публичные API. Для всех трёх домов 23-26 ноября и 2 взрослых получен правильный дом, диапазон и тариф. Бронирования и заявки не создавались.
- На главной запросов widget.js до прокрутки: 0; после приближения к форме: 1. Меню закрывается, заголовок бронирования на 111,75 px ниже верха, FAQ/Pet friendly работают.
- Контрольные хеши 10 файлов с коммерческими/юридическими сведениями и обработкой заявок совпадают с main (`validation/protected-content.json`).

Результаты и логи находятся в `validation/`. Подробные Lighthouse JSON и скриншоты доступны локально и исключены из коммита; краткие результаты сохранены в репозитории.

## Скорость и ограничения измерений

Два финальных мобильных запуска локальной production-сборки: главная 82/83 Performance, 100 Accessibility, 100 SEO; LCP 4,85/4,81 с, передано около 1,12 MB. LCP остаётся выше целевых 2,5 с и требует дальнейшего измерения после публикации на VPS. Эти результаты не являются обещанием production-балла: локальный сервер имеет другие задержки, localhost не разрешён поставщиком SDK. Реальная совместимость SDK проверялась отдельно указанным выше способом.

Повторный SiteGuru до публикации продолжит анализировать прежний production. После одобренного деплоя необходим новый обход и замер публичного домена. Полевые INP/CWV и фактическая индексация требуют Search Console/Вебмастера; текущий SiteGuru не подключён к GSC.

## Внешние задачи

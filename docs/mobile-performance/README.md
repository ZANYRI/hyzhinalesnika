# Мобильная оптимизация — 5 ноября 2026

Локальная ветка: `perf/mobile-2026-11-05`. База: `74e12c8` (опубликованный main на начало работы). Изменения этого этапа ещё не отправлены на сервер.

## Изменения

- Мобильный фон первого экрана: AVIF 85 114 → 56 717 байт (−33,4%). Сохранены фотография, кадрирование 576×1024 и затемнение. Сжатие усилено; сравнение сделано под штатным затемнением. WebP, настольный оригинал и старые версионные файлы сохранены. Генератор обновлён.
- Добавлены подмножества Moderustic 300–800 с основными русскими и латинскими символами. Оригинальные полные шрифты продолжают обслуживать редкие символы через unicode-range. Для трёх начертаний на главной экономия составляет 19 200 байт. Контуры букв, метрики, хинтинг и сведения о лицензии проверены генератором.
- Уточнены sizes фотографий домов и блоков главной. На планшете 768px фото в «О нас» шириной 720px раньше получало файл 384px; теперь выбирается 750px при DPR=1. На телефоне 390px/DPR=2 обложка дома выбирает 750px вместо 828px.
- FAQ стал Server Component. Нативные details работают без JavaScript. Открытие ответа о питомцах перенесено в существующий контроллер переходов.
- Исправлена резервная кнопка календаря: на узком экране текст переносится внутри блока. До исправления страница booking при ширине 320px имела scrollWidth 385px; после — 320px.

## Оставшееся и выпуск

- LCP 3,3 с сохраняет запас для дальнейшего улучшения; целевой ориентир 2,5 с пока не достигнут. Нельзя выдавать локальную оценку за полевые Core Web Vitals.
- После согласованного деплоя нужны повторный мобильный PageSpeed на основном домене и проверка реального календаря поставщика, включая выбор конкретного дома. Эти сценарии ограничены на локальном домене.
- Проверка выполнена в Chrome с мобильными viewport. Нужна отдельная приемка на физическом iPhone/Safari и Android.
- При выпуске использовать чистую production-сборку: в одной локальной повторной сборке кеш сохранил старые font-face; пересоздание генерируемой .next устранило их. В окончательном CSS старых неограниченных объявлений Moderustic нет. Новые шрифты уже в Git, Python на сервере не требуется.

Уверенность в исправлениях и проверенной геометрии высокая; в переносе размера выигрыша на production — средняя, до повторного замера после выпуска.

13 ноября 2026 года. Страница `/otdyh-s-zhivotnymi`, локальные изменения без публикации.

Добавлен отдельный блок перед условиями проживания: логотип партнёра, описание бесплатного набора, шесть составляющих, уточнение состава для поездки с кошкой и ссылка на проект партнёра. Набор описан отдельно от доплаты за размещение животного.

## Источники

- Предоставленная владельцем презентация `Четыре_Лапы_Пет_френдли_территория (1).pptx`, слайд 1: бесплатный набор для гостей отелей и глэмпингов. Из презентации взят горизонтальный логотип. Обещания о скидках и предложения для ресторанов на страницу не переносились.
- Существующий общий `PET_FAQ`: миска, лакомство, салфетки для лап, пакеты для уборки, пелёнка и игрушка. Условия проживания, категории и суммы доплаты сохранены без изменений.
- https://petfriendly.4lapy.ru/ — официальный проект партнёра, прочитан 13 ноября. На страницу добавлена ссылка; общие правила других заведений и возврата их имущества к нашему набору не приписывались.

## Реализация

- Next.js Metadata API и существующий `withSocialMetadata` используются для метатегов.
- Сведения о базе, ссылки на дома, FAQ и разметка присутствуют в серверном HTML.
- `LodgingBusiness` содержит адрес, телефон, описание, карту и текст условий проживания с питомцами.
- `Accommodation` содержит вместимость, площадь, фотографии, кухню, санузел и связь с базой. На главной описаны все три объекта.
- Новые производные лесного фото воспроизводятся командой `node scripts/prepare-forest.mjs`; проверка — `node scripts/prepare-forest.mjs --check`.
- `changes.diff` содержит изменения исходников и манифеста. Шесть изображений находятся отдельно в `public/images/home/`; бинарные данные в текстовый diff не включены.

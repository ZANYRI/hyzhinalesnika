## Следующие действия

1. Перед деплоем визуально проверить главную, три страницы домов, СПА и страницу с животными на телефоне: переносы новых заголовков, карточки активностей, кадрирование увеличенной фотографии реки. Проверить сетевую загрузку изображений при необходимости.
2. После одного согласованного деплоя проверить новые метаданные и серверные тексты на production. Отправить шесть адресов из `recrawl-urls.txt` на переобход и проверить обновлённый sitemap (18 URL). До публикации новый URL на индексацию не отправлять.
3. Сопоставить следующий доступный замер Яндекса с исходным по тем же регионам и устройствам. Проверить, начинает ли поиск выбирать страницы домов по соответствующим запросам. Рост позиций не гарантируется.
4. Контентные правки для СПА, бассейна и отдыха с животными включены в этот релиз. После переобхода проверять позиции и фактические релевантные URL. Дальнейшие изменения оценивать по данным, без обязательных повторных платных аудитов.
5. При повторении задержек проверить серверные логи и измерения из сопоставимой сети. Текущий аудит сам по себе не определяет причину задержек.

Не требуют изменений по этим данным: дубли корня со слешем и без него; пустые alt декоративных иконок; длина действующего URL путеводителя. Короткие description юридических страниц не увеличивались ради порога аудитора.

Уверенность высокая в локальных проверках, сохранении условий и доступности новых текстов в HTML; средняя в прогнозе выбора изображения браузером и влиянии контентных изменений на позиции.
